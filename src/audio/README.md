# 절차적 오디오

`createAudio()`는 첫 사용자 입력에서 `unlock()`을 호출한 뒤 사용한다. ZzFX 1.4가 모듈 평가 중 AudioContext를 만들기 때문에 동적 import를 사용한다. 준비 전 BGM 요청은 마지막 곡만 보존하며, 첫 클릭 효과음은 700ms 이내에 준비됐을 때만 재생한다.

- master → 출력, sfx/bgm → master의 독립 GainNode. 값은 0~1로 제한한다.
- BGM은 25ms 간격으로 120ms 앞을 예약한다. 숨긴 탭에서는 현재 곡을 일시정지하고 이전 곡의 페이드 잔향도 정리한다.
- 같은 곡의 중복 요청은 무시한다. 음표 종료 시 노드를 연결 해제한다.
- 효과음은 최대 24개 동시 재생, 잦은 발걸음·물소리는 최소 70ms 간격을 둔다.
- 12곡은 각각 16마디의 서로 다른 동기·응답 선율로 구성한다. 선율은 지정 선법 안에서 생성하며 보컬을 사용하지 않는다.

검증: `npm test -- tests/audio`, `npm run test:accept -- tests/audio`, `/dev/audio-test.html`. 브라우저 버튼 재생과 전곡 OfflineAudioContext 렌더링으로 무음·비정상 샘플·클리핑을 확인했다. 실제 스피커에서의 음색·편안함에 대한 청취 평가는 별도로 필요하다.
