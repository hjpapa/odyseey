# 오디세이 캐릭터 — 2026-11-07

## 방향과 적용 범위

기존 임시 블록을 그리스 신화에 맞는 절차적 3D 모델로 교체했다. 로블록스풍 비율과
어린이용 표정은 유지하고, 짧은 키톤·긴 페플로스·샌들·청동 장비·어깨띠·망토로 시대감을 준다.
이는 어린이 게임을 위한 양식화이며 엄밀한 시대별 복식 복원은 아니다.

- 인물 27명, 동물·괴물 9종을 등록했다.
- 검·방패·활·화살·삼지창·전령 지팡이·마법봉 7종을 등록했다.
- 오디세우스는 투구 5종, 튜닉 색과 망토 색/없음 옵션을 반영한다.
- 선원·병사·구혼자·연꽃족은 4가지 색상 변형을 지원한다.
- 배경 소품 48종은 이번 캐릭터 디자인 작업 범위 밖이며 기존 대역을 유지한다.

## 연결 규칙

- `registry.ts`를 통해 타이틀·섬·바다·기존 모델 갤러리에 자동 적용된다.
- `torso/head/armL/armR/legL/legR` 및 장비 부착점 이름을 유지한다.
- 머리와 팔은 몸통 아래, 머리 장식은 머리 아래, 손의 소품은 해당 팔 아래에 있다.
- 오디세우스의 손은 비워 둔다. `Player`가 검·방패를 한 번만 부착한다.
- 모델 루트의 스케일은 1이며 크기는 내부 조립 그룹에 반영한다.
  `SeaStage`가 포세이돈의 루트 스케일을 3으로 설정해도 의도한 크기를 유지한다.
- 실제 바운딩 박스의 발바닥은 Y=0, 높이는 `userData.height`와 일치한다.
- 지오메트리와 `MeshToonMaterial`은 공유한다. 개별 인물의 색/투명도를 바꿀 때는
  기존 적 엔진처럼 재질을 복제해야 한다. 공유 자원을 인물 하나 제거할 때 dispose하지 않는다.
- 게임의 `Player`는 현재 방패색 옵션을 `makeProp`에 전달하지 않는다. 이번 작업은
  엔진 파일을 수정하지 않았으며, 방패 빌더 자체는 `opts.avatar.shieldColor`를 받을 수 있다.

## 확인 방법

`npm run dev` 후 `/src/models/review.html`을 연다. 대표 인물 보기, 전후 비교,
개별 인물 선택, 정면/뒷면, 걷기·공격·점프 자세와 주인공 꾸미기를 확인할 수 있다.
기존 `/dev/model-gallery.html`도 그대로 사용할 수 있다. 검수 페이지는 개발 서버 전용이다.

검수 당시 실행 중인 주소: `http://127.0.0.1:5184/src/models/review.html`

## 검증과 한계

- 타입 검사와 프로덕션 빌드 통과.
- 일반 테스트 77개 통과(그중 신규 캐릭터 회귀 검사 39개).
- 기존 A4 수용 검사: 메시 예산·재질·색상 변형·꾸미기 4개 통과.
  전체 91종 등록 검사는 배경 소품 48종이 미등록이므로 실패한다. 테스트는 변경하지 않았다.
- 샌드박스 실행에서는 Vitest 임시 변환 파일 ENOENT가 발생했다.
  동일한 `npm test`를 일반 로컬 실행으로 재확인하여 11개 파일 / 77개 테스트가 통과했다.
- Chrome에서 대표 5인, 전후 비교, 뒷모습/걷기, 외눈 거인, 스킬라, 부엉이 및
  1·2장 게임 렌더링 확인. 전 챕터 플레이 및 실제 태블릿 성능 검증은 하지 않았다.
- 게임 콘솔에 기존 `PCFSoftShadowMap` 제거/대체 경고가 있다. 캐릭터 관련 런타임 오류는 관찰되지 않았다.
- 이 문서는 최초 로컬 미술 검수 기록이다. 이후 공개 릴리스에는 기존 1·2장 엔진·스토리 구현을
  함께 포함한다. 실제 커밋·배포 상태는 GitHub 이력과 Vercel 배포 기록에서 확인한다.

캡처는 `review-captures/`에 있다.
