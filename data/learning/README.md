# 학습 콘텐츠

- 영어 325개: 1학년 120개, 2학년 106개, 3학년 99개. 10개 주제별 15개 이상.
- 한자 91자: 한국어문회 8급 50자, 7급II 31자, 7급 10자.
- 예절 74개: 9개 분류, 1·2·3학년 각각 25·25·24개, 정답 위치 각각 25·25·24개.

기존 예시의 ID와 내용은 유지했다. 기존 1학년 예시인 `sheep`은 5글자 예외이며, 새 1학년 단어는 3~4글자다. 영어 그림은 단어를 돕는 이모지이며 숫자·가족 관계 등은 한국어 뜻과 함께 확인한다. 3학년 예문은 6단어 이내다.

한자의 훈과 음은 분리한다. 예를 들어 `山`은 `hun: "메"`, `eum: "산"`이다. 급수 표준 훈을 보존하고 예시 뜻은 어린이용으로 풀어 썼다. `女`의 표준 훈 등 옛 표현은 시험 표기이며, 예시에서는 현대적인 표현을 쓴다.

급수·훈음·획수 대조에 사용한 자료:

- [한국어문회 급수배정](https://www.hanja.re.kr/kccpt/exam/levelConfirm.do) — 원 발표 기관. 이번 확인 때 원 사이트는 502 응답.
- [어문회 자료를 옮긴 8급 표](https://funsoft.co.kr/hanja/table/8/), [7급II 표](https://funsoft.co.kr/hanja/table/7-2/), [7급 표](https://funsoft.co.kr/hanja/table/7/) — 신습 급수·대표훈음·총획을 대조했다.

예절의 추가 문항은 정답 위치를 순환 배치한다. 힌트는 상대의 마음, 차례, 허락, 안전을 생각하게 하고 정답 문장을 그대로 되풀이하지 않는다. 위험한 약속은 지키도록 요구하지 않는다.
